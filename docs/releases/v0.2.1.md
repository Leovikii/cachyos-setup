# v0.2.1

- 修复“安装跳过测速”将没有 `bootmnt` 目录的 CachyOS Live CD 误判为“不适用”；覆盖用户反馈的 `copytoram=auto` 启动环境。
- Live 标记改用 `/run/archiso`，并兼容 `ID=cachyos` 及上游 Live 配置的 `ID=arch` 与 `NAME=CachyOS`；保留对普通 Arch Live 和已安装系统的区分。
- 系统标识不可读时显示“无法检查”；新增基于官方 Live 身份的回归测试，覆盖单文件发行版。

已有脚本可通过“检查更新”升级。使用时先从欢迎界面打开安装器，停留在配置页面，再应用“安装跳过测速”。
