# v0.2.0

- 系统微调新增“安装跳过测速”：在 CachyOS Live ISO 中跳过 Calamares 安装测速，固定 CachyOS CDN77 和官方 Arch CDN，保留普通/v3/v4 架构变量。
- 先从欢迎界面打开安装器，停留在配置页面后应用，再直接继续安装；重新从欢迎界面启动会覆盖测速脚本，需再次应用。
- 支持只读状态、修改预览、确认后内部 sudo 备份与写入、重复执行跳过和手动恢复。未知测速脚本结构及符号链接会被拒绝。
- 镜像列表会复制到安装后的系统；本功能不修改安装后的测速定时器。Live ISO 重启后本次修改和备份会丢失。

下载 `cachyos-setup.sh` 后以普通用户运行 `bash cachyos-setup.sh`，不要 sudo 整个脚本。`SHA256SUMS` 提供文件校验。
