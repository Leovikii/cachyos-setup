# v0.2.0

本版本重新发布，补齐自动依赖安装、分类批量安装，并修复部分 Live CD 误报“不适用”。已有脚本请通过“检查更新”重新获取；版本号保持 0.2.0。

- 所有功能在确认后自动安装缺失的执行依赖并复查，缺少 Python、Qt 工具等不会在安装前直接退出；预览、状态和取消不安装包或写配置。
- 桌面美化、游戏设置、系统微调均新增“安装全部”；一次确认后顺序执行适用项，遇错停止并保留已完成项及备份。也支持 `--apply-all desktop|gaming|system`。
- 缺少原生 Steam 时自动安装；KDE 需要 AUR 时自动补齐构建依赖及 paru（没有现有 helper 时）。保留 pacman/AUR 的正常确认、完整系统升级和 PKGBUILD 审阅。
- 字体、窗口装饰、图标和光标由脚本自动安装并应用；已安装但组件不可用时尝试重新安装或构建，校验通过后再应用外观。

- 系统微调新增“安装跳过测速”：在 CachyOS Live ISO 中跳过 Calamares 安装测速，固定 CachyOS CDN77 和官方 Arch CDN，保留普通/v3/v4 架构变量。
- 先从欢迎界面打开安装器，停留在配置页面后应用，再直接继续安装；重新从欢迎界面启动会覆盖测速脚本，需再次应用。
- 支持只读状态、修改预览、确认后内部 sudo 备份与写入、重复执行跳过和手动恢复。未知测速脚本结构及符号链接会被拒绝。
- Live 检测使用 `/run/archiso`，覆盖没有 `bootmnt` 的 `copytoram=auto` 启动环境，并兼容 CachyOS Live 的两种发行版标识。
- 镜像列表会复制到安装后的系统；本功能不修改安装后的测速定时器。Live ISO 重启后本次修改和备份会丢失。

下载 `cachyos-setup.sh` 后以普通用户运行 `bash cachyos-setup.sh`，不要 sudo 整个脚本。`SHA256SUMS` 提供文件校验。
