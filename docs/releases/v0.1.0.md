首个发行版。

- 桌面美化：KDE 外观、更纱字体。
- 游戏设置：Proton 用户级全局预设、黑武士 5 Pro 按 Xbox 360 分类。
- 系统微调：Plasma Login Manager 登录界面仅显示主屏。
- 执行前预览确认，提供配置检查、备份恢复及脚本更新。

下载 `cachyos-setup.sh` 后，以普通用户运行 `bash cachyos-setup.sh`，不要 sudo 整个脚本；无需解压或克隆仓库。README 提供 latest Release 的 curl/wget 下载运行命令。

默认游戏预设为 117 FPS，需要匹配所用 Proton 和游戏。缺少软件时安装可能包含系统升级。应用后按提示重启 Steam 或注销重登。

附带 `SHA256SUMS`；产物由 GitHub Actions 从发行提交构建。此发行版不包含临时迁移兼容代码。
